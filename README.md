# 📄 AI Resume Analyzer

A Python-based Resume Analyzer that extracts text from PDF resumes and compares them with job-specific keywords.

## 🚀 Features

- Upload resume in PDF format
- Extract text from PDF using pdfplumber
- Analyze resume using spaCy NLP
- Count resume words
- Detect relevant entities
- Compare resume with required job keywords
- Identify missing keywords
- Interactive web interface using Streamlit

## 🛠️ Technologies Used

- Python
- Streamlit
- spaCy
- pdfplumber
- Natural Language Processing (NLP)
